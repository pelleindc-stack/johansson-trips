Maui Trip Offline Web App

QUICKEST IPHONE USE
1. Unzip the folder.
2. Open Maui_Trip_Offline.html from the Files app.
3. Use Share to keep it available in Files or send it to Renee.

TO INSTALL AS A HOME SCREEN APP
The folder must be hosted on an HTTPS website so Safari can register the offline service worker.
Easy hosts: GitHub Pages, Netlify Drop, or Cloudflare Pages.
After hosting:
1. Open the site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on Open as Web App, then Add.
5. Open it once while online. It will then work offline.

Apple Maps navigation still requires the West Maui offline map to be downloaded separately in Apple Maps.
